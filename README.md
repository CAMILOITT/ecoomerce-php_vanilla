# E-COMMERCE WEBSITE

Este es una tienda simple tienda virtual desarrollada con php puro, el cual permite a los usuarios navegar por productos, agregarlos a un carrito de compras y realizar pedidos.

## Funciones

- Navegación de productos: Los usuarios pueden ver una lista de productos disponibles con detalles como nombre, descripción, precio e imagen.
- Carrito de compras: Los usuarios pueden agregar productos a un carrito de compras, ver el contenido del carrito y eliminar productos si lo desean.
- Proceso de pedido: Los usuarios pueden completar un formulario de pedido con su información personal y detalles de envío.
- Gestión de productos: Un panel de administración simple permite agregar, editar y eliminar productos del catálogo.
- Buscador de productos: El usuario puede buscar el producto el cual esta interesado.
- Login usuario: Permite al usuario iniciar sesión y acceder al carrito de compras y a su perfil, con el historial de compras.
- Historial de compras: El usuario puede ver su historial de compras y el detalle de cada pedido.
- Login administradores: Los administradores tienen su propio login y panel de control para gestionar categorías, productos y pedidos.
- Dashboard: La pagina principal del administrador muestra estadísticas generales de la tienda, como el total de ventas, número de usuarios y productos en stock.

## Requisitos

- php versión 8.0 o superior.
- composer para la gestión de dependencias.
- Base de datos MySQL.
